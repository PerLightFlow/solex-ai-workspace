2026-11-06 调整。功能提交 `bd16a63484aff936e735000d9d061f7851d113bc`。

## 行为

- 资源卡片将“空间自有资源”改为“归属：当前共享空间名称”，并显示当前有效的编辑、下载能力。引用外部原件的资源继续显示“共享原件”，不把它误标为本空间所有。
- 权限来源按空间 ID 合并。同一空间的所有权路径与保留的共享路径只显示一次，不按名称合并不同空间。
- 来源描述为“你在某空间的角色是「编辑者」”，下一行标明该来源允许的编辑、下载能力。所有者、管理员、使用者显示各自真实角色。没有空间来源时不显示空的展开项。
- 后端合并来源说明时保留编辑、下载权限并集，以及最早的历史访问起点。授权总开关、原始共享记录、资源归属、成员与角色均未修改，不执行数据迁移。

重复的原因是资源移交给共享空间后，之前向同一空间发布的共享记录仍然存在；原实现将两条授权路径分别附在 `Access.Sources`。保留的记录可能影响可查看的历史版本，因此本次没有通过删除共享记录消除重复。
