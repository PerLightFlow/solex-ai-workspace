# 用户共享空间改造

2026-11-05 用户确认完整实施。基线：`2a5f195`。此文件记录实施和验收状态，不把未完成能力写成已上线。

## 已确认约束

- 每个账号一个私有个人空间，禁止邀请、加入他人的个人空间。
- 共享空间按用户加入；使用者、编辑者、管理员、所有者；默认使用者。
- 个人知识库默认只读共享，可单独开启允许修改原件和下载；成员不能擅自提升或转分享。
- 共享智能体必须显式选择已授权知识库，禁止作者全部知识库和隐式授权；会话文件生成保留。
- 修改人、时间、版本、冲突检查、恢复；内容版本默认30个，回收站30天，管理员可配置。
- 支持空间自有资源和个人资源移交；离职、退出、解散不能直接丢失团队资料。
- 后端所有访问途径、下载、Wiki、任务、旧聊天继续执行统一鉴权与撤权；展示多路径权限来源。
- 保留模型、工具和运行设置集中管理，以及个人聊天和产物私有。
- 迁移已有权限而不扩大权限，预览、备份、隔离演练后部署。
